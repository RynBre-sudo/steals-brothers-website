# 🎵 The Steals Brothers - Grammy Winners Website

A beautiful, fully-responsive website celebrating Melvin and Mervin Steals Sr., legendary songwriters and Grammy Award winners.

## ✨ Features

- 🌓 **Dark/Light Mode Toggle** - Switch between themes instantly
- 📱 **Fully Responsive** - Works on phones, tablets, and desktops
- 🎼 **7 Pages**:
  - Home - Overview and statistics
  - Meet the Twins - Photos and side-by-side bios
  - About Melvin - Full biography and career
  - About Mervin - Full biography and career
  - With You Jesus - New gospel single with purchase & streaming
  - Legacy & Discography - Timeline and complete song catalog
  - Contact & Booking - Message form and contact info

- 📸 **Photo Gallery** - Then & now images, historic photos
- 🎬 **Embedded Video** - YouTube video of "With You Jesus"
- 💾 **Purchase Integration** - Digital download with licensing tiers
- 📧 **Contact Form** - Working message form with validation

## 🎹 About The Steals Brothers

**Melvin Harold Steals Sr.** ("Lyric") and **Mervin Howard Steals Sr.** ("Mystro") are twin brothers born February 9, 1946, in Aliquippa, Pennsylvania.

### Notable Achievements:
- **4M+** radio spins for "Could It Be I'm Falling in Love"
- **100+** songs written and recorded
- **Grammy Award Winner** (2021) - "10%" by Kaytranada feat. Kali Uchis
- **Gold Certification** - "Could It Be I'm Falling in Love" by The Spinners
- **Philadelphia Soul Legends** - Worked with Gamble & Huff, Thom Bell, MFSB

### Latest Project:
**"With You Jesus"** - A gospel reimagining of their classic love song, available on Spotify, Apple Music, and YouTube.

## 📦 Installation

### Local Development:

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/steals-brothers-website.git
cd steals-brothers-website
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the website:
```bash
python steals_brothers_multipage.py
```

4. Open your browser:
```
http://127.0.0.1:8080
```
